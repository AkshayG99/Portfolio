- Built a supervised machine learning classification model in Python trained on NASA Kepler exoplanet data to predict planetary habitability scores across thousands of candidate planets.
- Performed end-to-end data analysis and feature engineering on multi-dimensional planetary datasets, processing variables such as planet mass, radius, surface temperature, stellar flux, and orbital period.
- Designed a modular pipeline with configurable retraining and serialized model persistence (using joblib/pickle), enabling reproducible inference without recomputation.
- Applied the trained model to a real-world colonization case study, ranking the top 5 candidate planets by predicted habitability score to identify the optimal target for human colonization.

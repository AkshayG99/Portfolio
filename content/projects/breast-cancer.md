- Developed a binary **Linear Classification model** in Python using TensorFlow to predict the presence of breast cancer based on patient diagnostic features.
- Achieved a high performance score with a minimized model **loss of 0.0959** and an **overall accuracy of 0.9681** (96.81%) on the validation dataset.
- Engineered a robust data preprocessing pipeline using Scikit-Learn to clean, scale, and normalize breast cancer diagnostic datasets, handling missing value imputations and feature correlation selections.
- Evaluated the classification boundaries and neural network performance using detailed confusion matrices, tracking precision, recall, and F1-score indicators.

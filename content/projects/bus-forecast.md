- Won **BramHacks out of 500 competitors** for an AI-powered bus route optimization tool that automates Brampton's surge bus allocation process.
- Designed an automated web scraper to collect upcoming Brampton events from Facebook.
- Built a machine learning model predicting event attendance using demographic and income datasets.
- Developed a visual analytics system highlighting high-demand bus routes in red for surge planning.
- Replaced the previous holiday-only manual bus allocation process with an automated system that continuously gathers event data and accounts for smaller surges and local events.
- Collaborated with Brampton Transit officials to address a key municipal transportation challenge through data-driven bus allocation.
- Created a centralized dashboard displaying events attendance forecasts and optimized bus routes.
